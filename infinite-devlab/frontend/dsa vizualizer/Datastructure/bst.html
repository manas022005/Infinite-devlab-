BINARY SEARCH TREE

Maintains elements in a sorted structure. The left child is always strictly less than the parent, right child is strictly greater. Enables fast lookups and insertions.

Core Rule
If val < node->val, go Left.
If val > node->val, go Right.
IDLE — Insert a number
// Ready to build the tree. Insert a value.
TreeNode* insertOrSearch(TreeNode* node, int val) {
  if (node == nullptr) return new TreeNode(val);
  if (val == node->val) {
    // Found target / Duplicate
    return node;
  } else if (val < node->val) {
    // Go Left
    node->left = insertOrSearch(node->left, val);
  } else {
    // Go Right
    node->right = insertOrSearch(node->right, val);
  }
  return node;
}
