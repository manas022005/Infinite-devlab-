TOP K ELEMENTS

Finds the K largest elements in an array using a Min-Heap of size K. Instead of sorting the whole array O(N log N), this optimizes the process to O(N log K).

Key Insight
A Min-Heap of size K keeps the smallest element at the top. If a new number is bigger than the heap's minimum, the minimum gets kicked out!

// Array generated. Ready to build heap.
vector<int> topKElements(vector<int>& arr, int k) {
  priority_queue<int, vector<int>, greater<int>> minHeap;
  for (int num : arr) {
    minHeap.push(num);               // Add to Heap
    if (minHeap.size() > k) {      // Heap exceeds size K
      minHeap.pop();               // Remove the smallest element
    }
  }
  return extractElements(minHeap);
}
